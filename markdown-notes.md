# Markdown Quick Reference

Headings: # H1, ## H2, ### H3
Bold: **text**   Italic: *text*   Strikethrough: ~~text~~   Inline code: `code`
Paragraph break: leave one full blank line between blocks
Line break without a new paragraph: end with <br>
Lists: - item (bullet), 1. item (numbered), indent 2 spaces to nest
Task list: - [x] done, - [ ] not done
Links: [text](url)  

Images: ![alt text](url)


Blockquote: > quoted text
Code block: ```language ... ``` (always close it!)
Table:
| Col A | Col B |
|-------|-------|
| a     | b     |
Horizontal rule: ---
